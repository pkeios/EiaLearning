# Cursos para construir

`/crear-curso` toma el primer curso sin marcar (`- [ ]`), lo arma, lo prueba, lo publica y lo marca con `- [x]`.
El usuario autorizó el 2026-11-13 que cada curso de esta lista se arme sin preguntarle el nombre, el público ni la bibliografía: los define `/crear-curso` investigando cursos parecidos.
Formato de cada línea: `carpeta` · Nombre de trabajo · para quién · categoría (la sección del inicio donde va la tarjeta).
Para cambiar el orden, mové las líneas. Para agregar un curso, sumá una línea con el mismo formato.
